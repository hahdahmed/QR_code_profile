# QR Code Profile — Mr. Mahmoud Abdel Aziz

A responsive, static profile page for a Chemistry Teacher.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Publish for free with GitHub Pages
1. Create a new GitHub repository named `qr-code-profile`.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/qr-code-profile/`

## QR code
Create the QR code only after the live website URL is available. The QR code should point to the published page URL, not to a local file.
